Problem 痛點分析

我們解決了目前市場上求職者與企業端面臨的核心問題[cite: 1, 2]：

資料過度碎片化

求職者的個人資料散佈在 LinkedIn、GitHub、各式求職網站以及個人電腦中[cite: 1]。學生族群的記錄更被封閉在校務系統（如 Moodle、eLearn）內，難以提取。

履歷客製化成本過高

求職者難以針對不同職缺，快速從龐雜的資料中萃取重點；導致資方無法精準評估候選人真實價值，目標客戶對現有解決方案感到挫折[cite: 1, 2]。

Solution 解決方案

OmniResume 是一個雙向賦能的整合系統，我們的產品運作方式如下[cite: 1, 2]：

  • 一鍵跨平台聚合： 透過 API 與爬蟲技術，安全串接校務系統與外部專業平台，自動匯集使用者的數位經歷[cite: 2]。
  • AI 智能萃取與優化： 導入自然語言處理技術，根據求職者的職涯目標與職缺需求，自動重組並優化履歷的重點呈現，帶來極大效益[cite: 2]。
  • 企業端結構化分析： 為資方提供標準化、數據化的候選人價值報告，解決未滿足的招募需求[cite: 2]。

Traction 牽引力

證明客戶對產品的需求以及我們的成長策略[cite: 1, 2]：

  • 用戶獲取 (CAC & LTV)： 透過校園大使與職涯工作坊進行早期低成本獲客，優化獲客成本與終身價值比例[cite: 2]。
  • 核心指標： 追蹤獨立新活躍用戶數、用戶留存率 (Retention Rate) 以及淨推薦值 (NPS)[cite: 2]。
  • 增長策略： 預計透過校園 B2B2C 授權，達成首年指數型成長[cite: 2]。
